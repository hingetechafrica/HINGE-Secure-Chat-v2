# HINGE-Secure-Chat v2
### HINGE TECH - Building Secure Technology For Africa

**HINGE AI v2** is an offline cybersecurity chatbot for Nigerian businesses.
It answers questions about phishing, ransomware, WhatsApp security, Zero Trust, SOC, NDPC, EFCC, and 50+ other topics — with NO internet, NO API key, NO cost.

---

## v1 vs v2 - What Changed?

| Feature | v1 | v2 |
| :--- | :--- | :--- |
| Answers | 20 simple answers | 52 detailed topics |
| Matching | Exact match only | SMART scoring - understands meaning |
| Example | Must type "phishing" exactly | Understands "how do hackers steal WhatsApp?" |
| Safety | No guardrails | Guardrails block hacking / malware requests |
| Follow-up | None | Asks "Want step-by-step for business or yourself?" |
| Design | Basic | Modern HINGE TECH Blue #0A2540, chat history, quick buttons |
| Offline | Yes | Yes - 100% Flask + Python |

Download from python.org. Tick "Add Python to PATH" during install.

Create a folder called `HINGE-Secure-Chat-v2` and put these 4 files inside:
- `chatbot.py`
- `app.py`
- `requirements.txt`
